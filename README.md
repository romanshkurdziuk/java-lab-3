# ✈️ Система Управления Фабрикой Дельтапланов

Комплексное консольное Java-приложение для автоматизации учета продукции на фабрике дельтапланов.
Проект разработан в рамках выполнения **Лабораторных работ №3 и №4**.

> **Статус проекта:** Завершен (Реализованы коллекции, I/O, паттерны проектирования, тесты)

---

## 📋 Основной Функционал

### 1. Управление данными (CRUD)
*   **Создание**: Добавление новых дельтапланов вручную или через генератор шаблонов.
*   **Чтение**: Просмотр полного списка продукции в табличном виде.
*   **Обновление**: Редактирование характеристик существующих аппаратов.
*   **Удаление**: Удаление записей по ID.

### 2. Работа с файлами и форматами
*   **Мультиформатность**: Поддержка сохранения и загрузки данных в форматах **TXT**, **JSON**, **XML**.
*   **Архивация**: Встроенная функция создания резервных копий (Backup) всех данных в **ZIP-архив**.
*   **Безопасность**: Возможность сохранения данных в зашифрованном виде (**AES Encryption**).

### 3. Сортировка и Валидация
*   Гибкая сортировка по Модели, Цене и Дате производства (используя `Comparator`).
*   Строгая валидация вводимых данных (защита от некорректных чисел, дат и пустых полей).

## 🏗️ Архитектура и Паттерны (Design Patterns)

В проекте реализованы ключевые паттерны проектирования для обеспечения гибкости и чистоты кода:

### 🛠️ Builder (Строитель) + Director
Используется для создания сложных объектов `HangGlider`.
*   **Builder**: Позволяет пошагово конструировать объект, задавая только нужные параметры (`setId`, `setModel`...).
*   **Director**: Содержит "рецепты" для быстрого создания стандартных конфигураций (например, *Beginner Glider* или *Pro Glider*).
*   *Файлы: `Builder.java`, `HangGliderBuilder.java`, `Director.java`*

### 🎁 Decorator (Декоратор)
Используется для добавления дополнительного поведения (шифрования) к процессу записи файлов без изменения основного кода.
*   **EncryptionDecorator**: Оборачивает базовую запись в файл и прозрачно шифрует/расшифровывает данные алгоритмом AES.
*   *Файлы: `DataSource.java`, `FileDataSource.java`, `EncryptionDecorator.java`*
